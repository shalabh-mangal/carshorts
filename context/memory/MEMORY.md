# Supervisor memory index (carshorts-relevant mirror)

repo (git) — a fresh Claude on a NEW machine reads this instead of losing context.
The live source lives outside the repo in `~/.claude/.../memory/`; unrelated/private
memories are deliberately not mirrored. **Refreshed 2026-07-28.**
